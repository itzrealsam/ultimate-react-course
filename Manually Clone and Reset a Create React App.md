# ⚡ React Project Cloning & Git Reset Cheat Sheet

Use this workflow to duplicate an existing `create-react-app` project, reset its files back to the day it was generated, change its name, and start tracking a brand-new Git history from scratch. This skips the long `npx create-react-app` download process.

## 📋 Prerequisites
Before running these commands, ensure you are in your terminal, inside the **newly copied folder**, and press **`q`** if you ever get stuck inside a text-viewing screen (like `git log`).

---

## 🛠️ Step-by-Step Workflow

### 1. View History to Find the First Commit
Find the original commit hash generated by `create-react-app` (usually at the very bottom of the log).
```bash
git log --oneline
```
*📌 **Action:** Copy the 7-character code (hash) next to the very first commit (e.g., `3f2f5e8`).*

### 2. Time-Travel Back to the Clean Template
Instantly wipe away all components, styles, and custom logic added after the initial setup.
```bash
git reset --hard <YOUR-INITIAL-COMMIT-HASH>
```
*(Example: `git reset --hard 3f2f5e8`)*

### 3. Wipe Git History Completely
Destroy the old project's commit history so it doesn't carry over into your new project.
```bash
rm -rf .git
git init
```

### 4. Rename the Project
Open **`package.json`** in your code editor and update the name field:
```json
{
  "name": "your-new-project-name",
  "version": "0.1.0",
  "private": true
}
```
*(Optional: Also change the `<title>` tag inside `public/index.html`).*

### 5. Establish the True New Initial Commit
```bash
git add .
git commit -m "Initial commit for new project"
```

### 6. Verify and Run
Launch the development server to ensure the pristine, default React template boots up.
```bash
npm start
```

## ⚙️ Quick Git Configuration Commands

If you need to configure or verify your identity inside this new repository, use these helper commands:

* **Set Identity Locally** (Applies *only* to this project folder):
  ```bash
  git config user.name "Your Name"
  git config user.email "your.email@example.com"
  ```
* **Set Identity Globally** (Applies to *all* future projects on this computer):
  ```bash
  git config --global user.name "Your Name"
  git config --global user.email "your.email@example.com"
  ```
* **Verify Current Credentials & Source File**:
  ```bash
  git config --show-origin user.name
  git config --show-origin user.email
  ```

## 🚀 Alternative for Next Time: Vite
If you want a truly fast workflow without copying old folders, stop using the deprecated `create-react-app`. **Vite** sets up a brand new React application in under 5 seconds:
```bash
npm create vite@latest my-new-app -- --template react
cd my-new-app
npm install
npm run dev
```
